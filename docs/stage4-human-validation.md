## 人工窗口的具体核对点

- 原生 APN 方法、PDP 1／2／3、消息明文标志、SIM 前端 0／1 到固件 1／2 和 LTE／NR 锁定参数需要在当前固件核对；若出现差异，保留失败结果再修适配，不把离线桩当作固件证据。
- Wi-Fi／LAN／访问限制先记录当前值。访问限制是候选自己的“禁止上网”规则；确认不会影响用户自建规则。LAN 可能断开连接，候选跳转保留当前端口。
- 网络 ADB 的旧 setprop／adbd 路径、USB 原生 mode 枚举、sysfs 性能／灯／wakelock 的实际支持范围尚未确认。需要相应固件能力或辅助程序，缺失时应明确不可用，不能默认为已关闭或已生效。
- ttyd 目标版本需支持 loopback／base-path／origin 参数；验证认证后的同源终端、退出及进程归属，勿开放原版终端端口。
- 限额断流只有 worker 与相应写权限启用后生效；日／月统计按 UTC，仅包含候选观察期。本月校准不改写原始每日记录。
- 未确认的 `running` 任务需要人工查看实际设备状态，再决定是否重新启用；本轮没有自动重试这种可能已经执行过的操作。
- NTP 与独立签名更新必须由用户指定来源；本轮仅测试回调／本地桩，没有联系真实时间、更新或消息服务。签名更新安装及服务恢复仍留实机验收。
- 原厂密码同步、已有 Wi-Fi 密码二维码、旧 Android APK／DIAG 路径和原版专属云功能不纳入当前主要功能交付；不为这些项目重复索取凭据或设备操作。
